# Value metric selection

A good value metric is the unit the customer pays for. It should pass four tests.

1. **It tracks value.** It goes up when the customer gets more out of the product. Check it against net expansion and account health, not just revenue.
2. **It survives seat cuts.** AI agents now do work that used to need people. If a metric falls as AI use rises, like seats or weekly active users, it shrinks revenue from your best customers.
3. **Buyers can forecast it.** Finance teams need to budget for it. Pick a metric with a smooth trend that customers can already see in the product.
4. **It is hard to game.** Customers should not be able to lower their bill without getting less value.

## Method
- Read the base overview, then run the metric analysis.
- Rank metrics by how well they track net expansion and health.
- Flag any metric that falls as AI adoption rises.
- Check concentration. If the top 10% of accounts drive more than half of usage, tier design matters more than the unit price.
- Recommend one metric and one runner up. Explain the trade off in two sentences a CFO would accept.
